```md
Estado: propuesta / lista / en-progreso / bloqueada / completa

Nivel: 0 / 1 / 2 / 3 / 4

## Problema Y Valor
## Usuario Y Flujo
## Alcance
## Fuera De Alcance
## Contrato / Invariantes
## Dependencias Y Entorno
## Criterios De Aceptación
- [ ]
## Casos Negativos
## Verificación
## Riesgos Y Rollback
```
