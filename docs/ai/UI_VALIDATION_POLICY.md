# Validación UI/UX

Compilar no prueba que una interfaz sea correcta.

## Evidencia

- ancho amplio, intermedio y compacto cuando aplica;
- teclado, foco y disabled;
- loading, vacío, error, éxito y permiso insuficiente;
- acción primaria y navegación real;
- contraste y labels;
- funcionalidad y side effects preservados.

## Criterios

- patrones y componentes existentes;
- densidad operativa adecuada;
- tablas utilizables sin cortar acciones;
- formularios con validación útil;
- responsive por ancho real, no zoom/DPR;
- ninguna acción decorativa.

Una preferencia estética no bloquea; pérdida funcional, accesibilidad, seguridad o inconsistencia con el sistema visual sí.
