# Política De Refinamiento

Refinar cuando el pedido no define comportamiento observable, admite decisiones con tradeoffs o afecta datos, dinero, permisos, seguridad o integraciones sin reglas suficientes.

## Salida Mínima

- problema y usuario;
- alcance y fuera de alcance;
- hechos, supuestos y bloqueantes;
- opciones/tradeoffs si aplica;
- criterios de aceptación;
- nivel de riesgo y verificación;
- próximo paso único.

No crear documentos para microcambios ni usar refinamiento para postergar un pedido ya claro. Un supuesto crítico requiere autorización explícita.
