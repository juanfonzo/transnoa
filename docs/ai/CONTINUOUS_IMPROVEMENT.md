# Mejora Continua Del Kit

## Principio

No convertir cada fricción en una nueva regla. Mejorar el kit con evidencia, repetición o riesgo real.

## Flujo

1. Registrar señal breve en `docs/kit-improvement/inbox.md`.
2. Buscar cobertura existente y señales con el mismo fingerprint.
3. Descartar, observar, fusionar o promover.
4. Promover una sola ocurrencia sólo si afecta seguridad, datos, permisos, producción o compromiso contractual.
5. Cambiar una fuente canónica y enlazar desde las demás.
6. Preservar conocimiento específico antes de compactar.
7. Ejecutar checks y evals del kit.

Preferir skills focales y referencias bajo demanda a ampliar indefinidamente `AGENTS.md`.
