# Lecciones Activas

Registrar sólo aprendizajes repetibles que cambien decisiones futuras y todavía no tengan una policy canónica. No usar como historial de tareas.

- El selector de rol demo no debe tomarse como evidencia de autorización.
- Antes de ejecutar Prisma o SQL, identificar y confirmar el entorno de base de datos cuando pueda ser compartido.
